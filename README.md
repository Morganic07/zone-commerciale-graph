# Hypothèse : pas d'apesanteur

Les stations simulent la gravité (gravité artificielle). On y marche comme sur Terre :
les vitesses, débits et capacités de `epic2_donnees/donnees/parametres.json` sont donc
ceux d'une personne au sol (vitesse de marche normale : 1,34 m/s). Une personne à
mobilité réduite est une personne en fauteuil roulant.
